# 解法の地図 — 高校数学 解法パターン対応表

高校数学（数学I・A・II・B・C・III）の全単元について、
「こういう問題が来たら → こう考える → こう解く → この定理を使う → なぜその方法なのか」
を対応づけた学習サイトです。基礎から阪大理系数学レベルまで段階的に学べます。

## 構成

- `index.html` … トップ（単元一覧・使い方）
- `roadmap.html` … 学習ロードマップ
- `thinking.html` … 単元横断の「発想の引き出し」
- `reverse.html` … やりたいことから解法を探す逆引き索引
- `handai.html` … 阪大理系数学の対策（傾向・時間配分・答案の書き方）
- `units/*.html` … 単元ページ（基本事項・早見表・パターン別解法・よくあるミス・阪大型演習）
- `assets/` … 共通 CSS / JS、数式描画用 KaTeX（同梱）

ビルド不要の静的サイトです。GitHub Pages でそのまま公開できます。
