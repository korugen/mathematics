# 解法の地図 — 高校数学 解法パターン対応表

高校数学（数学I・A・II・B・C・III）の全単元について、
「こういう問題が来たら → こう考える → こう解く → この定理を使う → なぜその方法なのか」
を対応づけた学習サイトです。基礎から阪大理系数学レベルまで段階的に学べます。

## ページ

| ファイル | 内容 |
|---|---|
| `index.html` | トップ（進み具合のダッシュボード・使い方・単元一覧） |
| `units/*.html` | 単元ページ：基本事項・早見表・パターン別解法（例題・類題・図）・よくあるミス・阪大型演習 |
| `roadmap.html` | 学習ロードマップ（時期別の計画、1日の回し方） |
| `thinking.html` | 単元横断の「発想の引き出し」と、各発想を使うパターンの一覧 |
| `reverse.html` | 目的（最大最小、解の個数、整数解…）から解法を探す逆引き索引 |
| `drill.html` | パターン判定ドリル（単元を隠した類題で、方針を選ぶ練習） |
| `review.html` | 復習リスト（翌日・3日後・1週間後に自動で出題、記録の書き出し） |
| `search.html` | サイト内検索 |
| `handai.html` | 阪大理系数学の対策と、阪大型演習の一覧 |

学習記録はブラウザの localStorage に保存されます（サーバには送られません）。

## 構成と更新手順

- `assets/site.js` … 共通スクリプト（ナビ、数式描画、自己判定と復習、ドリル、検索、ダッシュボード）
- `assets/style.css` … 共通スタイル（ライト/ダーク対応、印刷用スタイル）
- `assets/katex/` … 数式描画用 KaTeX 0.16.11（同梱）
- `assets/data/` … 単元ページから生成するデータ（直接編集しない）
- `tools/build_data.py` … `assets/data/patterns.js`・`drill.js` を生成
- `tools/build_reverse.py` … `reverse.html` を生成

単元ページを編集したら、次を実行してから公開します。

```sh
python3 tools/build_data.py
python3 tools/build_reverse.py
```

ビルド不要の静的サイトなので、GitHub Pages でそのまま公開できます。
